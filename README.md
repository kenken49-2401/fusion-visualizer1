# Fusion 人形立て 3Dビューア

Fusion から書き出した 3MF を、スマートフォンや PC のブラウザで確認するための静的ビューアです。Three.js・TypeScript・Vite を使用し、GitHub Pages で配信できます。閲覧にはログイン不要です。

公開画面では回転・拡大縮小・視点変更、ボディの選択、寸法の確認ができます。形状や公開色の編集機能はありません。iPhone の Safari を主な対象としていますが、実機での最終確認は下記の手順で行ってください。

## モデル

同梱ファイルは実際の「人形立て」モデル `public/models/figure-stand.3mf` です。3MF の単位は mm、ボディは `ボディ2` の 1 個、三角形は 68 枚、元の色は黒（`#000000`）です。

| 対象 | 寸法・設定 |
| --- | --- |
| 元データの X / Y / Z | 40 / 1000 / 1500 mm |
| 表示する幅 / 奥行 / 高さ | 1000 / 40 / 1500 mm |
| 上方向 / 正面方向 | Z / X |
| ボディ ID | `build:0/object:1` |

寸法はメッシュの外接寸法です。3MF はメッシュデータなので、Fusion の履歴・拘束・パラメータなどの CAD 編集情報は含みません。汎用の GLB / STL インポーターや CAD エディターではありません。

## 開発

Node.js 24 を推奨します（Vite の要件は Node.js 22.12 以上）。アプリはリポジトリ直下にあります。

```sh
npm ci
npm run dev
```

開発サーバーは `127.0.0.1:5173` を使用します。通常閲覧と色編集のサーバーは同時起動せず、切り替えるときは先に終了してください。

```sh
npm test
npm run build
npm run preview
```

ビルド結果は `dist/`、プレビューのポートは `4173` です。ブラウザの自動テストを実行する場合は次を使用します。

```sh
npx playwright install chromium
npm run test:e2e
```

これらは検証コマンドの案内です。iOS Safari の実機動作を保証するものではありません。

## 管理者の色変更

書き込み権限のある管理者が手元のチェックアウトで実行します。

```sh
npm run dev:admin
```

ボディを選択して色をプレビューし、保存すると `public/viewer.json` のボディ ID ごとの色設定が更新されます。元の色に戻す操作は、そのボディの色上書きを削除します。必要なら JSON をバックアップ用にダウンロードできます。

保存はローカルファイルの更新までです。差分を確認してコミットし、`main` に push すると公開用ワークフローが実行されます。モデルそのものを変更せずに公開色を更新できます。同時編集による競合が表示された場合は、再読み込みして最新の設定を確認してから保存し直してください。

管理機能は開発用 admin モードだけで有効になります。ローカル専用の `GET /__admin/config` と `POST /__admin/colors` が設定を読み書きし、通常の公開ビルドには管理画面コードや保存用サーバーは含まれません。GitHub Pages 上の訪問者が元の設定を書き換えることはできません。

## GitHub Pages への公開

`.github/workflows/pages.yml` は `main` への push と手動実行に対応します。依存関係の固定インストール、ユニットテスト、ビルドを行い、成果物を Pages に配信します。プロジェクトサイトのパスは Pages の設定から `BASE_PATH` に渡します。

初回はリポジトリの **Settings → Pages → Build and deployment → Source** が **GitHub Actions** であることを確認してください。ワークフローは Pages の自動有効化も試みますが、組織の方針や権限によって手動設定が必要です。公開先 URL は成功した Actions の `github-pages` デプロイ結果で確認できます。

公開された HTML・JavaScript・設定・3MF は訪問者が取得できます。ダウンロードさせたくないモデルや機密情報は置かないでください。公開色を変更できるのは、元リポジトリへ変更を反映できる共同作業者です。

実行時の資産は同じ配信元から読み込み、外部 CDN、ログインサービス、Blender は不要です。開発依存関係の取得には npm レジストリを使用します。初回表示には通信が必要で、オフライン PWA ではありません。

## 更新と動作確認

モデル差し替えの手順は [docs/model-update.md](docs/model-update.md) を参照してください。

公開前に、PC と iPhone Safari で次を確認してください。

- モデルと色が表示され、ドラッグで回転、ピンチで拡大縮小できる。
- 立体・正面・右側面・上面の視点と全体表示が適切で、幅・奥行・高さが意図した値になる。
- 縦向き・横向きの両方で操作でき、ページのスクロールやボディ選択が妨げられない。
- 公開サイトに保存や色編集の UI がなく、リポジトリ名を含むパスでもモデルが読み込まれる。
