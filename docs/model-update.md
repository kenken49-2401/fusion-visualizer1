# モデルを差し替える

1. Fusion から対象のモデルを 3MF として書き出します。上方向・正面方向と実寸を控えてください。CAD の履歴は 3MF に含まれません。
2. `public/models/figure-stand.3mf` を新しいファイルに差し替えます。別のファイル名にする場合は `public/viewer.json` の `model` を、`public/` からの相対パスで変更します。
3. `public/viewer.json` の `title`、`description`、`updatedAt` と `upAxis`、`frontAxis` を確認します。同梱の人形立ては Z が上、X が正面です。形状に応じて設定し、正面からの幅・奥行・高さを確認してください。
4. `npm run dev:admin` を起動し、モデルの単位・寸法・ボディ一覧・元の色を確認します。ローダーは 3MF の単位を読み取り、mm に換算します。想定寸法と異なる場合は Fusion の書き出し設定と元データを確認してください。
5. ボディ ID と色設定の対応を確認します。`colors` はボディ名ではなく ID をキーにします。ID は build 項目と object ID、コンポーネントがある場合はその階層のインデックスと object ID から構成されます。形状の再書き出しで ID が変わることがあるため、以前の設定をそのまま流用せず、新しい一覧に合わせて不要な色上書きを削除し、必要な色を保存してください。
6. `npm test`、`npm run build`、必要に応じて `npm run test:e2e` を実行します。ブラウザで向き・寸法・色・選択・タッチ操作を確認してから、モデルと設定の差分を一緒にコミットします。

同梱モデルの基準値は、元の X / Y / Z が 40 / 1000 / 1500 mm、表示の幅 / 奥行 / 高さが 1000 / 40 / 1500 mm、ボディ `ボディ2` の ID が `build:0/object:1` です。モデルを差し替えた後は、この基準値と README の説明も更新してください。

色変更だけならモデルの再書き出しは不要です。公開サイトには編集機能がないため、ローカルで保存した後に GitHub へ反映し、Pages のデプロイ成功を確認してください。
